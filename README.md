# bibliothek-cli

Agent-CLI für den LIV-Bibliothekskatalog (OPAC HHN/DHBW Heilbronn).

- Katalog live durchsuchen, Treffer filtern, Detail-Datensätze lesen
- Lokaler Keyword-Watch (Datei-basiert, kein Server)
- Login am Bibliothekskonto per Env-Variablen, Ausleihen lesen,
  Verlängern nur mit `--confirm`

Status: Wird gebaut.
